## NER

### Ashesh's prompt

> Perform named entity recognition on this tweet:
>
> "Loved the Apple event in Cupertino. Tim Cook introduced the Vision Pro while #AppleEvent was trending."
> 
> Identify at most three well-known named entities explicitly
> mentioned in the tweet. Each should be identifiable in a
> reference source such as Wikipedia.
> Return a Markdown bulleted list in this format:
> - Entity: One-sentence description
> Do not extract hashtags as entities. Do not invent entities.

## Product Description

### Ashesh's prompt

> Write a short, compelling product description for
> an advertisement promoting the LuminaFold Desk Lamp.
> Product specifications:
> - USB-C powered
> - Three adjustable brightness settings
> - Foldable arm
> - No built-in battery
> - No wireless charging
> Target audience: College students.
> Requirements:
> - 40–70 words
> - Positive, persuasive tone
> - Highlight relevant product benefits
> - Do not invent additional product features
> - Do not include prices or discounts

### KK's Prompt

## SVG Design

### Ashesh's prompt

> Redesign the Kodak logo for a contemporary digital age.
> Design goals:
> - Modern, clean, minimalistic visual appearance
> - Maintain recognizable connections to Kodak's heritage
> - Incorporate red and yellow into the identity
> - Suitable for digital applications and app icons
> - Visually balanced, distinctive, and legible
> Technical requirements:
> - Generate a complete, standalone SVG
> - Include a viewBox
> - Use vector elements only
> - No external images, fonts, or dependencies
> - The design should remain recognizable at small sizes

### KK's Prompt

> Generate an SVG logo redesign of Google fitting of the contemporary age. Feel free to be creative and unpredictable, it does not have to reflect the present day logo.
