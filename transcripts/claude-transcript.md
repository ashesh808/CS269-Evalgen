- **Styling:** the site's `themes.js` copied as is, its Google Sans Flex and Maple Mono fonts, and its navbar, boxes, buttons and Aa menu (4 palettes, light/dark/auto, text size).

**Compared with the upstream repo**
1. Upstream's grader never saw the assertion, because the code passed `criteria=` to a template expecting `assertion`. The templates now raise an error on any missing variable.
2. Upstream stopped after running the assertions. I added the paper's §4.2 coverage, false failure rate (FFR) and alignment scores, picking one assertion per criterion under an FFR threshold, and a report card. Changing a grade or the threshold updates the report without new model calls.
3. Two parts of the paper are not implemented:
   - Code-based assertions, since running model-written Python needs a sandbox.
   - The grading sampler that picks which output to grade next; all outputs are shown at once.
4. Streamlit is replaced by FastAPI serving a static page, since Streamlit can't carry the site's palette and mode switching.

**Checks:** ruff, black, pyright, import-linter and the unit tests all pass, and so does the live test. In a full run with real criteria, assertions, samples and grades, the evaluate call took 81s for 24 grader calls.
